Thermal scan report

Each scan is compared with the first scans of the same recording. Whole-scene drift (camera or room) is removed, so the change map shows local changes only. Cold changes are the leak-type signal (evaporating spray or liquid, expanding gas); warm changes are usually people or heat they leave behind.

The CSVs have no timestamps, so time is shown as scan number. Values are °C from the camera's radiometric export.
